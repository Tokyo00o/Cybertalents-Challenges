# Silent Look

> **Category:** Reconnaissance · **Challenge Type:** Fundamentals

---

## Challenge Description

> Gathering as much information as possible without establishing contact between the pen tester and the target which you are collecting information.

## Solution

The key detail is **“without establishing contact.”** The question describes a reconnaissance approach that gathers information from existing, publicly accessible sources rather than interacting directly with the target.

This is the distinction between **passive** and **active** reconnaissance: active reconnaissance involves directly querying or probing the target, while passive reconnaissance avoids that contact.
