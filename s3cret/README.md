# s3cret

> **Challenge:** I need to remove a file called `s3cret` in my home directory. Which command should I use?

---

## Solution

In Linux, `rm` removes a file, while `~` refers to the current user's home directory. Combining them with the filename targets the file in the home directory without needing to write its full path.

---

<details>
<summary><strong>🚩 Reveal Answer</strong></summary>

```bash
rm ~/s3cret
```

</details>
